작게 열고 빠르게 복사

창을 크게 띄우지 않아도, 방금 지나간 텍스트를 다시 붙잡을 수 있습니다.

01

메뉴바에 머무는 기록

앱을 전환하지 않고도 최근 복사한 내용을 바로 확인하고 다시 복사할 수 있습니다.

02

중요한 문장은 고정

자주 쓰는 답변, 링크, 메모는 잠가두고 필요 없는 기록은 가볍게 비울 수 있습니다.

03

원하는 방식으로 조정

기록 개수, 텍스트 길이, 테마, 자동 닫기까지 쓰는 방식에 맞게 정리됩니다.

What it includes

필요한 것만 담았습니다

  • 최근 복사한 텍스트 모아보기
  • 다시 복사, 삭제, 잠금 처리
  • 한국어, English, 日本語, 中文 UI
  • 테마와 동작 방식 설정
  • 새 릴리즈 확인과 다운로드 연결

Installation

DMG로 간단하게 설치

  1. 최신 릴리즈에서 DMG를 받습니다.
  2. 앱을 Applications 폴더로 옮깁니다.
  3. 실행하면 메뉴바에서 바로 사용할 수 있습니다.

Ready to use

복사한 텍스트를 더 오래 붙잡아두세요.

최신 릴리즈를 내려받고, 메뉴바에서 필요한 기록을 바로 다시 꺼내면 됩니다.
