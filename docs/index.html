macOS Menu Bar App Oh My Clipboard
기능 릴리즈 다운로드

Clipboard, without friction

복붙 기록을 메뉴바에서 바로 꺼내 쓰는 방식

Oh My Clipboard는 macOS 메뉴바에 머무르며 최근 복사한 텍스트, 고정 항목, 다국어 UI, 빠른 설정 접근을 한 화면에 정리해주는 클립보드 히스토리 앱입니다.

최신 버전 받기 GitHub 보기
  • Menu Bar 앱 전환 없이 즉시 접근
  • Multi-language 한국어, English, 日本語, 中文
  • Release-based GitHub Releases로 바로 배포

왜 쓰는지

여러 번 복사했던 텍스트를 다시 찾기 위해 문서를 뒤지지 않도록 설계했습니다.

01

빠른 접근

메뉴바에서 바로 열리고, 필요한 텍스트를 다시 복사하는 데 집중한 구조입니다.

02

고정과 정리

중요한 항목은 잠가두고, 불필요한 기록은 바로 지울 수 있습니다.

03

설정 단순화

토글, 드롭다운, 테마 선택을 한 화면에서 빠르게 조정할 수 있습니다.

What it includes

핵심 기능

  • 최근 클립보드 텍스트 히스토리
  • 항목 복사, 삭제, 잠금
  • 다국어 UI 지원
  • 테마 및 동작 설정
  • GitHub Releases 기반 업데이트 확인

Installation

설치 방식

  1. 최신 릴리즈에서 DMG를 받습니다.
  2. `Oh My Clipboard.app`을 `/Applications`에 복사합니다.
  3. 메뉴바에서 실행 후 바로 사용합니다.

Ready to use

지금 바로 메뉴바에 올릴 수 있습니다.

소개 페이지는 GitHub Pages로 배포하고, 앱 배포는 GitHub Releases로 유지하는 구조입니다.
